# Dictate 1.4.0 (11)

- Escape cancels recording and the pending cleanup/insertion backlog. Delayed output checks
  the original app, window and field before pasting; changed focus falls back to manual paste.
- Recover interrupted or failed recordings locally, export audio/text, or delete them explicitly.
  Failed conversation audio is retained when recognition or transcript saving fails.
- Cleanup captures provider settings per recording, has a total deadline, and records safe errors.
- Vocabulary supports exact casing, individual removal and import/export. Cleanup uses relevant
  spelling hints. The current Apple speech recognizer is unchanged.
- Conversation capture preserves wall-clock timing across gaps and bounds restart attempts.
- Clipboard format preservation, provider output validation, and international spacing improve.
- Includes macOS/iOS regression CI, isolated previews, evaluation tooling and license notices.

Recognition and recovery stay on-device. Optional remote cleanup receives text, relevant learned
hints, explicit vocabulary and custom instructions. See the updated canonical privacy policy.

Remaining compatibility/quality checks and English UI fallback coverage are documented in
[reliability verification](../reliability-verification.md). This release does not claim actual paste
acknowledgement from third-party editors or measured real-speech quality improvements.
