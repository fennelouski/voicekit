# Dictate 1.5.0 deployment — October 26, 2026

Dictate **1.5.0 (12)** is published as the latest, non-prerelease
[GitHub release](https://github.com/fennelouski/voicekit/releases/tag/v1.5.0), at the
[stable download](https://nathanfennel.com/downloads/Dictate.dmg), and through the
[existing Sparkle feed](https://nathanfennel.com/downloads/appcast.xml). The feed advertises
build 12 with a full archive and deltas, including an update from 1.4.0. The canonical product
and privacy pages reflect the new default local insertion and opt-in polishing behavior.

The app and DMG passed Developer ID signing, hardened runtime, Apple notarization, stapling,
and Gatekeeper. All 18 archive/delta signatures verified against the app's embedded public
key. Applying the 1.4.0-to-1.5.0 delta produced a valid signed app whose executable matches
the full release. The mounted DMG contains the same signed 1.5.0 executable. Downloading
both GitHub assets and checking SHA256SUMS confirmed the published bytes.

The complete local suite passed: **261 macOS tests, seven iOS simulator tests, three Python
tests**, bundle/permission/license/40-locale validation, shell syntax and whitespace checks.
Four microphone/ASR tests remain explicit opt-ins. Real editor delivery, ASR quality and
hardware latency measurements are not inferred from these checks.

The scoped native publisher uploaded 25 immutable release files to the existing AWS bucket.
Every file was verified at its origin and public URL without query parameters. Authenticated
staging checks verified the DMG, feed, product and privacy pages before routing promotion.
Three project routes serve only exact published native download filenames and Dictate's
product/privacy pages. An older direct archive was verified to continue using the existing
site. The production website deployment ID remains unchanged, preserving newer unmerged
website work. Full website AWS migration is still incomplete; this native release does not
change DNS, infrastructure, credentials, access controls or background-job ownership.

The verified prebuilt app was installed and remains running at `/Applications/Dictate.app`.
Its executable matches the notarized artifact. The previous 1.4.0 installation was retained
at `build/installed-backups/Dictate-1.4.0-20261026T182746Z.app` for rollback. This verifies
installation/startup and release availability, not a real microphone/editor interaction.

Source, hosting/routing versions, notarization IDs, hashes, check results and rollback details
are in [the deployment record](1.5.0-deployment.json). Native artifact/source publication is
separate from the preserved website deployment; the release-source branch is
`codex/dictate-1.5.0-native-release` in the website repository.
