# Dictate 1.5.0 (12)

- Fast local insertion is the default. AI polishing now requires explicit opt-in, including after upgrading; saved provider settings are preserved.
- Recognition prepares the selected language ahead of the hotkey without recording idle audio. Buffered capture preserves opening speech while preparation completes.
- Optional AI polishing has a two-second default deadline and falls back to local text when it takes too long. Adjust the budget in Cleanup settings.
- Local timing reports help diagnose capture, recognition, cleanup, and paste-event latency without logging transcripts or audio.
- Existing Escape cancellation, recording recovery, destination checks, and clipboard safeguards remain in effect.
- macOS and iOS regression suites now run locally with a pre-push verification hook.

Requires macOS 26 or later and Apple Silicon. Recognition stays on-device. Optional remote
polishing sends text and configured spelling hints to the provider you choose.

No measured microphone-to-editor speedup is claimed. Hardware/ASR compatibility, real editor
delivery, and translation review remain separate checks described in the verification documents.
